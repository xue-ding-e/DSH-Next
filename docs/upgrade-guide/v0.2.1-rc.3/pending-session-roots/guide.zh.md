# 会话目录请求快照

[English](guide.md) | 中文

## 变更

具有非空附加目录默认值的新 Workspace 会话会记录必需事件 `sandbox/roots-requested`。不认识该事件的旧读取器会拒绝日志，而不是丢弃目录选择。不含该事件的既有日志仍可读取。事件存储待确认请求而非执行授权；恢复或导入不会授予额外写权限。

## 迁移

1. 在共享新日志之前，将用于恢复、分叉或导入这些会话的每个 DSH 读取器升级到认识 `sandbox/roots-requested` 的版本。
2. 保持事件完整。不要为使旧读取器接受日志而删除事件或将其标为可忽略。
3. 使用升级后的读取器重新打开含该事件的会话，确认待确认选择已恢复且主 cwd 不变。本变更不提供目录激活与选择 UI。

参见[持久化兼容记录](../../../persistence-changes/2026-11-01-pending-session-roots.zh.md)。
